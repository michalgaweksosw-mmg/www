Zaloguj się do panelu

Panel zapisuje wpisy i zdjęcia bezpośrednio w repozytorium strony na GitHubie. Do logowania potrzebny jest token dostępu — działa jak hasło tylko do tej strony.

Repozytorium

Skąd wziąć token? (jednorazowo, ok. 2 minuty)
  1. Zaloguj się na GitHubie na konto, które ma dostęp do repozytorium strony.
  2. Otwórz formularz nowego tokenu — nazwa i uprawnienie do zapisu wypełnią się same.
  3. W sekcji Repository access wybierz Only select repositories i zaznacz repozytorium strony (www).
  4. Sprawdź, że w Permissions → Repository permissions pozycja Contents ma wartość Read and write.
  5. Kliknij Generate token, skopiuj token i wklej go powyżej. Zapisz go w bezpiecznym miejscu — GitHub pokazuje go tylko raz.

Token jest wysyłany wyłącznie do GitHuba. Gdy wygaśnie albo wycieknie, usuń go na GitHubie i utwórz nowy.
