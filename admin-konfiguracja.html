Konfiguracja panelu

Jednorazowe połączenie panelu z repozytorium (powtarzane tylko, gdy token GitHub wygaśnie). Token zostanie zaszyfrowany hasłem i zapisany w repozytorium — potem w panelu logujesz się już tylko loginem i hasłem.

W panelu są już konta. Nowa konfiguracja usunie wszystkie dotychczasowe konta — pozostałe osoby trzeba będzie dodać ponownie.

Jak utworzyć token?
  1. Otwórz formularz nowego tokenu (zalogowany na koncie właściciela repozytorium).
  2. Repository access → Only select repositories → repozytorium strony (www).
  3. Repository permissions → Contents → Read and write.
  4. Generate token → skopiuj i wklej powyżej.
